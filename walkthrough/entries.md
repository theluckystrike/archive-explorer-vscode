# Open entries in editor tabs

Double-click a file in the archive view, or press Enter. It opens read-only in a normal tab:

- Code and text get syntax colors from VS Code.
- Images open in the image preview.
- CSV, Parquet, PDF, Word and other files open in the viewer you have installed for that type.
- A ZIP inside a ZIP opens as another archive.

Use Open to the side to compare two entries. Entries over the size limit can be extracted instead.
